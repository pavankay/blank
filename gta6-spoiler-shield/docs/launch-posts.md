# Launch posts

One post per platform, from your own account. Replace `[LINK]` with the Chrome Web Store link (or your GitHub release) before posting.

## Before you post

- **Get a link people can trust.** Publish to the Chrome Web Store (one-time $5 developer fee, review usually takes a few days), or put the extension in its own public GitHub repo with a release zip. The current repo also contains unrelated code, so it's not a good link to share.
- **One account, one post per place.** Posting the same thing from several accounts, or in many subreddits or servers at once, gets flagged as spam and can get the accounts and the link banned. Say plainly that you made it.
- **Check each community's rules first.** Many gaming subreddits and Discord servers ban self-promotion outside a weekly thread or a specific channel. When in doubt, message the mods first.
- **Show, don't tell.** A 10-second screen recording of a feed going from full of spoilers to shielded does more than any caption. The best moment to film: open YouTube or X, search "GTA 6", and toggle the shield on.
- **Stick around.** Reply to comments for the first hour. If people report something that slipped through, that's free bug reports.

## LinkedIn (builder angle)

> GTA VI launched this week, and for a lot of people the hardest part of playing it slowly will be avoiding spoilers.
>
> So I built Spoiler Shield, a Chrome extension that hides spoilers by topic across about 30 sites. A few things that were more interesting than expected:
>
> • Deciding what is "about GTA VI" needs a context score, not a keyword list. "The ending" is a spoiler under a GTA VI video and harmless on a cooking blog.
> • Social media text is messy: glued hashtags (#GTA6Spoilers), fancy Unicode fonts, invisible zero-width characters. All have to be normalized first.
> • "No spoilers" is one of the most common phrases in spoiler-free content, so it has to be read as a promise, not a trigger.
> • Every network structures a "post" differently, so each one needs its own rules plus a fallback that finds "one card in a feed" anywhere.
>
